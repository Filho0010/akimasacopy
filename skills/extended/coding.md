# Extended Skills — Coding

通常は読まない。プログラムの作成・改修、デバッグ、テストなど、実装作業の進め方に型が必要な場合に参照する。

### systematic-debugging
use: バグ、テスト失敗、想定外の動作に当たった時。修正を試す前に、根本原因を特定する4段階の手順を使う
not: 原因が特定済みで、修正内容も明確な場合
source: https://github.com/obra/superpowers/tree/main/skills/systematic-debugging

### verification-before-completion
use: 実装や修正の完了を報告する前。確認コマンドを実際に実行し、証拠をもって完了を主張する手順を使う
not: 作業途中の進捗報告、確認を伴わない単なる状態共有
source: https://github.com/obra/superpowers/tree/main/skills/verification-before-completion

### grilling
use: プログラムや設計を作り始める前。計画・設計・案について、決定事項を木構造に洗い出し、AIが推奨案つきの質問を重ねて曖昧な前提を潰してから着手する
not: 既に仕様と判断基準が固まっている場合、軽微な修正
source: https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling
